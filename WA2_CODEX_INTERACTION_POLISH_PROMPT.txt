WHITE ALBUM 2 — CODEX ULTRA INTERACTION POLISH PROMPT

Continue from the CURRENT completed WHITE ALBUM 2 website.

This is NOT a redesign from zero.

Do NOT re-read:
- the full design brief
- old reference repositories
- external reference websites
- previous research already completed in this Codex conversation

Treat all previous typography, layout, visual-direction, media, and reference decisions as established.

This pass is ONLY for upgrading interaction design of clickable text, CTA controls, links, and a small number of important UI elements.

==================================================
1. MAIN GOAL
==================================================

The current site already looks good, but some clickable text/buttons still feel too plain and functional.

Make important interactions feel:
- emotional
- winter-like
- elegant
- premium
- quiet
- tactile
- visually authored
- appropriate for a visual novel
- unmistakably WHITE ALBUM 2

The interaction language should evoke:
- snow
- frost
- memory
- silence
- music
- restrained emotion

Do not make it flashy, magical, or fantasy-like.

The user should feel like they are entering a memory, not clicking a normal web CTA.

==================================================
2. PRIMARY TARGETS
==================================================

Prioritize:

1. Entry screen
   - Enter with sound
   - Continue in silence

2. Hero CTA
   - Begin the first movement
   - equivalent story CTA if wording changed

3. Music controls
   - sound toggle
   - main play/pause button
   - Music Room track rows
   - story-sync toggle

4. Important navigation / ending links
   - chapter rail
   - important section transitions
   - ending / return-to-top CTA

Do NOT animate every small link on the page.

==================================================
3. CORE WINTER INTERACTION SYSTEM
==================================================

Create ONE coherent micro-interaction language based on snow/frost.

Good techniques:
- thin frost line forming on hover
- underline appearing like a line traced through snow
- tiny snow accumulation along a 1px line
- cold shimmer passing softly through text
- subtle frost clearing from letters
- tiny powder-snow particles dispersing on click
- underline softly breaking apart into snow
- controlled cold-to-warm accent for music-related actions
- slight text clarity/brightness shift like fogged glass clearing

Do NOT use every idea.

Choose a restrained combination and use it consistently.

The interaction system should feel emotional and authored, not like a CSS demo.

==================================================
4. ENTER WITH SOUND
==================================================

This should be the slightly warmer and more inviting choice.

IDLE:
- elegant readable text
- fine line / underline treatment
- subtle warm-gold music accent may remain
- do not put it inside a large box

HOVER / KEYBOARD FOCUS:
- frost line forms or becomes clearer
- very soft shimmer through the text
- slight warm undertone appears beneath the cold palette
- optional tiny snow motes, used sparingly
- text remains perfectly readable

PRESS / CLICK:
- tiny powder-snow dispersion
- frost line softly melts or breaks apart
- very small warm accent release
- no explosion
- no confetti
- no giant glow
- no long delay before the existing page transition

The current entry transition must remain the dominant motion.

==================================================
5. CONTINUE IN SILENCE
==================================================

This should feel colder, quieter, and more distant.

IDLE:
- slightly lower emphasis than Enter with sound
- still fully readable
- refined line treatment

HOVER / KEYBOARD FOCUS:
- cool-blue frost line
- text becomes slightly clearer / brighter
- line can appear as if drawn through fresh snow
- no warm accent

PRESS / CLICK:
- frost quietly recedes
- subtle snow retreat / dissolve
- fewer particles than the sound option
- extremely restrained response

Both entry options must clearly belong to the same visual system.

==================================================
6. VISUAL RULES
==================================================

KEEP the current:
- dark winter palette
- typography
- layout
- spacing
- image composition
- premium visual language
- overall WA2 mood

DO NOT:
- redesign the page
- replace fonts for novelty
- shrink text
- add excessive tracking
- create rounded SaaS buttons
- create pill buttons
- add generic filled CTA rectangles
- add glassmorphism
- add neon
- add blue-purple startup gradients
- add material ripple effects
- add spring/bounce animation
- add hover-lift cards
- add huge animated shadows

PREFER:
- 1px lines
- pseudo-elements
- masks
- opacity
- transform
- subtle gradients
- edge highlights
- lightweight shimmer
- small event-triggered effects

==================================================
7. SNOW / PARTICLE RULES
==================================================

If using click particles:

- use approximately 4–12 particles maximum per activation
- particles must resemble powder snow or frost dust
- particles should disappear quickly
- no permanent extra particle loop
- do not create hundreds of DOM nodes
- reuse a lightweight layer if possible
- preserve smooth FPS

Particles must NOT look like:
- stars
- sparkles
- magic spells
- fireworks
- fantasy energy
- confetti

==================================================
8. HERO CTA
==================================================

Refine the important hero/story CTA without turning it into a normal button.

Suggested behavior:
- fine underline or directional line at idle
- line extends / reveals on hover
- arrow moves only about 2–4px
- slight cold shimmer or frost trace
- click produces a tiny dissolve response before normal navigation

Keep it visually subordinate to the artwork and hero title.

==================================================
9. MUSIC CONTROL POLISH
==================================================

Do NOT rebuild the music system.

Keep the current:
- real local WA2 music
- Music Room layout
- story sync
- manual selection
- crossfade
- waveform
- volume
- play/pause

Only polish interaction.

PLAY / PAUSE:
- one restrained activation response
- slight ring/line pulse or tiny waveform reaction
- no large glow

SOUND TOGGLE:
- existing bars may become slightly more alive when playing
- subtle cold/warm state transition
- no flashy equalizer

TRACK ROWS:
- active track may gain a fine side line / frost trace
- hover can brighten the title and reveal a subtle directional line
- no card hover
- no background tile unless already part of the current visual system

STORY SYNC:
- readable, elegant ON/OFF transition
- no generic oversized mobile-style switch

==================================================
10. LINK / CTA MOTION
==================================================

For important text links:

IDLE:
- fine underline, partial line, or directional accent

HOVER:
- line grows from one side
- subtle frost/shimmer response
- text brightness changes slightly
- arrow moves 2–4px maximum

CLICK:
- line softly fragments/dissolves
- optional tiny powder-snow response

Suggested timing:
- hover: 180–350ms
- click micro-effect: 250–600ms
- emotional accent: up to ~800ms only if very subtle

Do not make the UI sluggish.

==================================================
11. PERFORMANCE
==================================================

Smooth performance remains a hard requirement.

Target roughly 60 FPS on an ordinary desktop GPU.

Prefer:
- transform
- opacity
- pseudo-elements
- event-triggered animation
- Web Animations API if useful
- requestAnimationFrame only when actually needed

Avoid:
- permanent extra animation loops
- heavy blur
- repeated backdrop-filter
- animating layout-heavy properties
- repeated forced layout reads/writes
- giant animated box shadows
- new heavy dependencies

Do NOT add GSAP, Framer Motion, Three.js, or another animation library for this pass unless already required by the existing implementation.

==================================================
12. ACCESSIBILITY
==================================================

Interactions must work for:
- mouse hover
- keyboard focus
- touch / pointer activation

Do not rely only on hover.

Keep a clearly visible focus state.

Do not remove outlines unless replacing them with an equally visible custom focus treatment.

Click effects must not delay actual actions noticeably.

==================================================
13. REDUCED MOTION
==================================================

Respect prefers-reduced-motion.

When reduced motion is enabled:
- disable snow particle dispersal from buttons
- disable shimmer sweeps
- disable nonessential movement
- preserve elegant static color/frost/underline/focus states

The UI should still look premium without animation.
